# OpenRabbit Agent System

## Overview
OpenRabbit is a modular AI agent built on OpenClaw architecture.
Its purpose is to assist with real estate analysis, lead generation,
market monitoring, and automation workflows.

## Core Functions
- Analyze MLS deals
- Evaluate investment properties
- Generate seller/buyer conversations
- Monitor target zip codes for undervalued properties
- Draft marketing content from Slack uploads
- Assist with contract and offer structuring

## Data Sources
- MLS API
- County Assessor Data
- Rental Market APIs
- OpenAI API
- Social Media APIs

## Workflow
1. User uploads content or data
2. Agent analyzes data
3. Agent produces draft output
4. User approves
5. Agent executes action

## Long-Term Vision
Create replicable AI agents for real estate professionals.
