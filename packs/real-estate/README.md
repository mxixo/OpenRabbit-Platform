# Pack: Real Estate

Intended composition:

- capabilities: `real-estate`, CRM (HubSpot or equivalent), knowledge/documents as needed
- integrations: MLS, Rentcast, HubSpot, email/calendar providers
- worker presets: Acquisitions Analyst, Research Analyst, Executive Assistant (subset)
- workflows: commercial investment analysis / underwriting

This pack extends OpenRabbit; it does not fork the platform.
